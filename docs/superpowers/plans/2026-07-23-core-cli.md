# core 개발/운영 보조 CLI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** travel-builder 모노레포의 `core/`에 commander 기반 TypeScript 개발/운영 보조 CLI를 스캐폴드하고, 동작하는 예시 명령 `hello` 하나를 구현한다.

**Architecture:** ESM(NodeNext) TypeScript 프로젝트. `src/index.ts`가 commander `program`을 배선하고, 각 명령은 `src/commands/*.ts`의 `registerXxx(program)` 함수로 등록된다. 비즈니스 로직은 순수 함수로 분리해 Vitest로 테스트하고, 콘솔 출력은 `src/lib/logger.ts`로 통일한다.

**Tech Stack:** TypeScript, commander, npm, Node.js, ESM, tsx(개발 실행), tsc(빌드), Vitest(테스트)

---

## File Structure

- `core/package.json` — 패키지 메타, `bin`, 스크립트, 의존성
- `core/tsconfig.json` — NodeNext + strict, `dist` 출력
- `core/vitest.config.ts` — Vitest 설정
- `core/.gitignore` — `node_modules`, `dist`
- `core/README.md` — 설치/사용법
- `core/src/index.ts` — CLI 진입점 (배선만)
- `core/src/lib/logger.ts` — 공통 출력 헬퍼
- `core/src/commands/hello.ts` — `greet()` 순수 함수 + `registerHello()`
- `core/tests/hello.test.ts` — `greet()` 단위 테스트

> **주의 (ESM/NodeNext):** TypeScript 소스에서 상대 경로 import는 컴파일 결과에 맞춰 `.js` 확장자를 붙인다 (예: `import { greet } from "./commands/hello.js"`). tsx와 tsc 모두 이 규칙을 따른다.

> **작업 디렉토리:** 모든 `npm`/`node`/`npx` 명령은 `core/` 안에서 실행한다. git 명령은 저장소 루트(`C:\workspace\travel-buider`)에서 실행한다.

- [ ] **Step 3: 최소 구현 (`core/src/commands/hello.ts`)**

```typescript
import type { Command } from "commander";
import { logger } from "../lib/logger.js";

/** 인사말 생성 (순수 함수). */
export function greet(name: string): string {
  return `Hello, ${name}!`;
}

/** commander program에 `hello` 명령을 등록한다. */
export function registerHello(program: Command): void {
  program
    .command("hello")
    .description("예시 인사 명령")
    .option("-n, --name <name>", "인사할 대상 이름", "world")
    .action((options: { name: string }) => {
      logger.info(greet(options.name));
    });
}
```

- [ ] **Step 4: 테스트 실행 — 통과 확인**

Run (in `core/`): `npx vitest run tests/hello.test.ts`
Expected: PASS — 2개 테스트 통과.
