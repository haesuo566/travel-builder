# 조건 분기의 한쪽만 테스트한다

**증상**
`A일 때 호출됨`은 있는데 `A가 아닐 때 호출 안 됨`이 없다. 성공 경로만 있고 실패 경로가 없다. 폴백 분기에 테스트가 없다.

**결과**
조건 분기가 통째로 사라지거나 반대로 뒤집혀도 테스트가 초록불을 준다.

**대응**
분기를 쓸 때마다 양쪽 방향 테스트를 짝으로 만든다. 리뷰에서는 spec 에러 처리 표의 **행 수와 테스트 수를 대조**한다. 의심되면 구현을 임시로 망가뜨려 돌려보고, 여전히 통과하면 확정 지적이다.
